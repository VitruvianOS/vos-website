After years of quiet development, the first public release of VitruvianOS is here.

## A long time coming

Work started back in 2019 with some early experiments. The first announcement was low-key — more of a signal to the handful of people who might care.

Porting a BeOS-compatible runtime onto Linux isn't repackaging existing tools. The whole infrastructure was built from the ground up — a layer that lets Tracker, Deskbar, and the rest of the Vitruvian desktop run as native Linux applications.

## What's in 0.3.0

This is a pilot release. A foundation that shows where things are headed.

- Boot from XFS and SquashFS with full extended attribute support
- Real-time patched Linux kernel for low-latency desktop use
- BeOS/Haiku API compatibility layer with native application support
- Deskbar, Tracker, and core desktop components
- Basic input system (enough for testing)
- Purpose-built graphics layer (neither X nor Wayland)

## What comes next

**0.3.1** (coming soon) fills in missing components and fixes bugs reported by early testers.

**0.3.2** moves closer to a self-hosting system — Vitruvian building itself.

**0.4** targets genuine stability, broader hardware support, and the ongoing ARM port.

## Who is this for

Testers, developers, and anyone curious about a BeOS-inspired Linux desktop.

If modern desktop environments frustrate you — the bloat, the complexity, the settings overload — give it a look. Same if you're into alternative platforms (ARM, RISC-V), hardware projects, or simply want to see how an OS can be built differently.

## Get involved

There are three of us right now, but growing. Developers, hardware people, testers, idea people — all welcome.

Daily builds are on the [Download](/download/) page. To get involved or ask questions, join [Telegram](https://t.me/vitruvian_official_chat) or open an issue on [GitHub](https://github.com/VitruvianOS/Vitruvian).

This isn't a corporate project backed by venture capital. If you'd like to support the work, [donations](https://wiki.v-os.dev/docs/reference/donate/) are appreciated.

## One more thing

What's been built isn't just a BeOS-compatible desktop — it's a different approach to what a Linux desktop can be. Decades of desktop OS development have been shaped by the X server model and later by Wayland. But what if you could step outside that?

Just getting started. Stay tuned.
